# 像素风肉鸽射击游戏

这是一款使用 Python 和 pygame-ce 开发的轻量俯视角射击游戏。玩家进入军事隔离区，在黑暗房间中寻找照明机关、清理僵尸、收集金币并购买强化。一局共三关，第三关商店之后进入两阶段 Boss 战。

游戏采用 32px 网格、房间模板池和 3/4 俯视像素画，使用软件渲染，不要求独立显卡。

## 运行环境

- Windows 10 或 Windows 11
- Python 3.12 或更高版本
- uv

## 安装和启动

在 PowerShell 中进入仓库根目录，也就是包含 `pyproject.toml` 的 `game/` 目录，然后执行：

```powershell
uv sync
uv run game
```

`uv sync` 会创建项目虚拟环境并安装依赖。以后启动游戏只需要在同一目录执行：

```powershell
uv run game
```

进入标题界面后按任意键开始新游戏。开始新游戏会重置金币和所有商店强化。

## 操作

| 场景 | 按键 | 功能 |
| --- | --- | --- |
| 游戏中 | 方向键 | 向上、下、左、右移动 |
| 游戏中 | F | 向角色当前朝向射击 |
| 游戏中 | E | 打开属性面板 |
| 属性面板 | E 或 ESC | 返回游戏 |
| 游戏中 | ESC | 打开暂停菜单 |
| 暂停菜单 | 上/下 | 选择继续游戏或返回标题 |
| 暂停菜单 | F | 确认选择 |
| 暂停菜单 | ESC | 继续游戏 |
| 商店 | 上/下 | 选择商品或出口 |
| 商店 | F | 购买商品或确认离开 |
| 商店 | ESC | 直接离开商店并进入下一关 |

游戏不使用 WASD。移动只绑定方向键。

## 怎么玩

进入尚未清理的房间后，房门会关闭。击败当前房间里的全部僵尸，房门才会重新开启。已清理的房间不会再次生成敌人。

未点亮的房间只有角色周围 224px 的圆形区域可见。找到并接触白色照明机关后，当前房间会永久点亮。障碍和箱子会阻挡角色、僵尸与子弹，僵尸冲锋撞上障碍后会进入短暂硬直。

清空本关的所有普通房间后会进入商店。商店可以提高攻击力、生命上限、射速和移速，也可以恢复生命。重复购买同一种强化会涨价，达到属性上限后不能继续购买。

战斗画面左上角只显示生命红心，不显示金币。一颗亮红心代表一点当前生命，一颗暗色空心红心代表一点已损失生命。红心每行最多三颗；即使生命上限提高到 10，红心也不会覆盖房间画面。金币仍会显示在属性面板和商店中。

关卡流程如下：

```text
第一关：固定 2 个普通房间，每房 6 至 8 个敌人 -> 商店
第二关：2 至 3 个普通房间，每房 8 至 10 个敌人 -> 商店
第三关：2 至 3 个普通房间，每房 11 至 13 个敌人 -> 商店 -> 两阶段 Boss 战
```

第二关每种僵尸比第一关多 1 点生命，伤害保持不变。第三关每种僵尸比第一关多 2 点生命，并增加 1 点伤害。后两关的快速和重型僵尸所占比例也更高。

## 敌人

| 类型 | 第一关生命 | 第二关生命 | 第三关生命 | 第一、二关伤害 | 第三关伤害 | 基础速度 | 行为 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 普通僵尸 | 5 | 6 | 7 | 1 | 2 | 1.2 | 接近角色后短距离冲锋 |
| 快速僵尸 | 3 | 4 | 5 | 1 | 2 | 2.0 | 移动较快，使用不能越过障碍的短跳扑 |
| 重型僵尸 | 8 | 9 | 10 | 2 | 3 | 0.9 | 生命和伤害较高，冲锋更快，但预警与硬直更长 |

普通、快速和重型僵尸的冲锋预警分别为 0.35、0.20 和 0.65 秒，冲锋速度分别为基础速度的 3、3 和 5 倍。冲锋结束后的硬直分别为 0.6、0.45 和 0.9 秒。可以引诱僵尸撞向柱子或矮墙，再趁硬直射击。

僵尸之间会保持距离。冲锋僵尸可以挤开其他僵尸，但不会对同类造成伤害或硬直。角色受到接触伤害后会与僵尸分开，并获得短暂无敌时间。

## 金币、箱子和死亡

僵尸和箱子都有 50% 概率掉落一枚金币。金币会在 20 秒后消失，角色接触金币即可拾取。

不计算箱子并假设击杀掉落全部拾取时，三关金币期望分别为 7、11.25 和 15 枚，合计 33.25 枚。攻击力从 1 升到上限 5 共需 20 枚金币，因此期望掉落足够在 Boss 战前升满攻击力。

每个普通房间至少有一个箱子。第一关整关会额外生成 0 至 1 个箱子，第二关额外生成 1 至 2 个，第三关额外生成 2 至 3 个。

生命归零后，按任意键重新开始当前关卡。已经购买的永久强化会保留，金币和当前关卡进度会清零。

## Boss 战

第三关商店结束后会进入完全点亮的独立 Boss 房。房内没有箱子、普通敌人或照明机关。Boss 第一阶段有 100 点生命，使用单次长距离冲锋；第二阶段有 50 点生命，移动和冲锋更快，预警与硬直更短，并连续冲锋两次。两次冲锋分别锁定方向，冲锋途中不会转向追踪。第一阶段冲锋造成 2 点伤害，第二阶段造成 3 点伤害。

Boss 名为“封锁区破城者”，是一名被感染的前军事封锁重装人员。第一阶段保留灰白防爆装甲，第二阶段胸背装甲破裂并露出暗红感染裂纹。Boss 撞到墙体或固定障碍后会进入硬直。第二阶段生命归零后播放约 1 秒死亡效果，随后显示“后续内容正在开发”。此时按任意键返回标题画面，不会再次进入商店。

## 美术资源

运行时 PNG 分别保存在 `assets/characters/`、`assets/environment/`、`assets/props/`、`assets/effects/` 和 `assets/ui/`。当前游戏继续使用兼容的单帧角色图；同目录中的横向 `_sheet.png`、Boss 和战斗效果资源可供后续动画接入。游戏优先使用 `assets/fonts/` 中随包发布的简体中文像素字体。角色按脚底 Y 坐标与场景物件排序，地面按 32px Tile 拼接，UI 面板使用九宫格缩放。

修改母版后可以重新生成运行时资源：

```powershell
uv run python tools/build_runtime_assets.py
```

制作母版如下：

- `assets/concepts/art_direction_board_v1.png`：整体风格板
- `assets/characters/character_turnarounds_v1.png`：角色四方向母版
- `assets/characters/character_actions_master_v1.png`：角色移动与攻击动作母版
- `assets/characters/character_hurt_death_master_v1.png`：角色受击与死亡动作母版
- `assets/characters/boss/boss_character_master_v1.png`：Boss 两阶段四方向母版
- `assets/characters/boss/boss_actions_master_v1.png`：Boss 硬直与死亡动作母版
- `assets/environment/environment_props_master_v1.png`：场景与物件母版
- `assets/environment/environment_decals_master_v1.png`：警戒、裂纹和污渍贴花母版
- `assets/effects/combat_effects_master_v1.png`：枪口、命中、冲锋和掉落效果母版
- `assets/effects/secondary_effects_master_v1.png`：箱子碎屑与玩家受伤效果母版
- `assets/ui/ui_master_v1.png`：UI 母版
- `assets/ui/heart_icons_master_v1.png`：满红心和空红心母版
