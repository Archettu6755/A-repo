# 游戏玩法说明

## 启动

在项目根目录执行：

```bash
uv run game
```

## 目标

一局包含三关。第一关有 2 至 3 个普通房间，第二关和第三关各有 2 至 4 个普通房间。玩家需要探索房间、启动照明机关、击败全部僵尸，并使用金币在关卡之间购买强化。第三关清空后先进入商店，再进入当前为空的 Boss 房；Boss 战及后续流程尚未确定。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 | 移动 |
| F | 向当前朝向射击 |
| E | 打开或关闭属性面板 |
| ESC | 暂停、返回或关闭面板 |
| 上/下 | 在商店切换商品 |
| F | 在商店购买或确认 |

## 房间

玩家进入未清理的战斗房后，房门关闭。击败当前房间全部敌人后，房门重新开启。已清理房间不会再次生成敌人；只有清空本关全部普通房间后才进入商店。

未点亮房间只有玩家周围 224px 的圆形区域可见。玩家接触照明机关后，当前房间永久点亮。

## 敌人

| 类型 | 基础速度 | 特点 |
| --- | ---: | --- |
| 普通僵尸 | 1.2 | 接近后短距离冲锋 |
| 快速僵尸 | 2.0 | 移动快，使用不能越过障碍的短跳扑 |
| 重型僵尸 | 0.9 | 生命和伤害高，冲锋预警与硬直更长 |

普通、快速和重型僵尸的冲锋预警分别为 0.35、0.20 和 0.65 秒，速度倍率分别为 3、3 和 5 倍，硬直分别为 0.6、0.45 和 0.9 秒。玩家可以利用柱子和矮墙中断冲锋，并在僵尸眩晕时攻击。

僵尸之间会保持间距。发生重叠时双方会被分开；冲锋僵尸可以挤开同类，但不会造成友军伤害。玩家受到接触伤害后也会与僵尸分离。

## 关卡流程

```text
第一关（2 至 3 个普通房间，10 至 12 个敌人） -> 商店
第二关（2 至 4 个普通房间，14 至 16 个敌人） -> 商店
第三关（2 至 4 个普通房间，18 至 20 个敌人） -> 商店 -> 空 Boss 房
```

Boss 房进入时完全点亮，只保留 Boss 数据位。房内没有机关、箱子、普通敌人或可见占位符。玩家可以移动，并通过暂停菜单返回标题界面。当前不包含 Boss 形象、设定、敌人实体、战斗或胜利条件。

## 金币和商店

僵尸和箱子都有 50% 概率掉落金币。金币存在 20 秒，玩家接触后自动拾取。

每个普通房间固定有一个箱子。第一关额外增加 0 至 1 个，第二关额外增加 1 至 2 个，第三关额外增加 2 至 3 个。Boss 房没有箱子。

商店可提高攻击力、生命上限、射速和移速，也可以购买治疗。重复购买会涨价，达到属性上限后商品锁定。

## 死亡

生命归零后重新开始当前关卡。商店购买的永久强化保留，金币和当前关卡状态清零。
