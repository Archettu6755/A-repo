# 游戏玩法说明

## 启动游戏

```bash
# 在 projects/ 目录下执行
uv run game
```

## 游戏目标

击败房间内**全部僵尸**即可通关。

- Demo 版共 **两关**。
- 通关第二关后回到标题界面，可反复游玩。

## 操作方式

| 按键 | 功能 |
| ---- | ---- |
| W / A / S / D | 移动（上下左右，斜走速度略快） |
| F | 射击（向当前朝向发射子弹，有冷却） |
| E | 打开/关闭属性面板（查看生命、攻击、射速、移速、金币） |
| ESC | 暂停 / 恢复 |
| 任意键 | 标题界面开始游戏 |
| ↑ / ↓ | 商店中切换选择 |
| 回车 | 商店中购买 / 确认 |

## 游戏流程

```
标题界面（按任意键开始）
  → 第一关：击杀全部僵尸
  → 商店：用金币购买强化
  → 第二关：房间重置、僵尸更多更强
  → 商店
  → 返回标题
```

## 敌人：僵尸

| 类型 | 血量 | 碰撞伤害 | 速度 |
| ---- | ---- | ---- | ---- |
| 普通僵尸 | 2 | 1 | 慢 |
| 快速僵尸 | 1 | 1 | 快 |
| 重型僵尸 | 3 | 2 | 慢 |

- 僵尸平时缓慢靠近，**距离你 200 像素内会冲锋**（速度 2.5 倍）。
- 冲锋撞墙、撞你或冲过头后，会**眩晕 0.5 秒**，这是攻击的好时机。
- 第二关僵尸数量更多、重型僵尸出现概率更高。

## 金币

- 击杀僵尸有 **50% 概率**掉落金币（1 枚）。
- 走过金币自动拾取。
- 金币 **20 秒后消失**，要尽快拾取。

## 商店

通关后进入商店，使用金币购买强化，**可重复购买**：

| 商品 | 价格 | 效果 |
| ---- | ---- | ---- |
| 攻击力 +1 | 5 金币 | 子弹伤害 +1 |
| 生命上限 +1 | 10 金币 | 最大生命 +1 |
| 射速提升 | 8 金币 | 缩短射击冷却 |
| 移速提升 | 8 金币 | 移动速度加快 |
| 回血 | 3 金币 | 恢复 3 点生命 |

- 金币不足时无法购买（显示灰色 + 红字提示）。
- 最后一项是"进入下一关"，确认后进入下一关（第二关时为"返回标题"）。

## 死亡规则

- 生命归零 → 本关失败，按任意键重开本关。
- 重开后：**强化保留**（攻击力/生命上限/射速/移速），**金币清零**、僵尸重生。

## 提示

- 初始生命 5 点，被僵尸碰到会扣血，受伤后有 0.5 秒无敌时间（角色闪烁）。
- 利用僵尸眩晕的 0.5 秒集中火力。
- 优先打掉快速僵尸（血少但贴身快），重型僵尸慢慢磨。
