# 地图设计规范

本文件是正式需求的一部分。地图实现和美术资源必须同时遵守 `docs/proposal.md` 与本文件。

## 1. 设计目标

地图服务于短距离射击、僵尸冲锋和黑暗探索。房间需要给玩家留出绕行空间，也要提供能够中断冲锋的掩体。随机性来自房间组合、模板变换、敌人位置和装饰，不来自任意矩形堆叠。

## 2. 坐标与网格

| 项目 | 规格 |
| --- | --- |
| 窗口 | 1280x720 |
| 可行走逻辑矩形 | 1024x576，屏幕坐标 `(128, 120)` |
| 逻辑网格 | 32x18 |
| 单格 | 32x32px |
| 可行走区域 | 32x18 格 |
| 外墙 | 位于逻辑矩形外侧，一格厚 |
| 含墙总包络 | 34x20 格 |
| 门洞 | 两格宽 |

角色以脚底中心作为世界坐标。碰撞框与显示画布分离，角色图片可以高于一个格子，但脚底不得偏离碰撞框中心。

## 3. 关卡拓扑

第一关固定生成 2 个普通房间，第二关和第三关各生成 2 至 3 个普通房间。生成器在小型二维坐标网格上放置房间，每次从出生房扩展一个相邻空坐标，直到达到目标数量。

第二关和第三关的 2、3 房等概率。

生成规则：

1. 所有房间连通。
2. 每个门在相邻房间中都有对应门。
3. 每关最多包含一个短分支。
4. 出生房位于拓扑端点。
5. 不生成环路和走廊。
6. 当前房间单独显示，跨门后切换画面。

第三关另有一个独立 Boss 房，不计入普通房间数量。玩家离开第三关商店后直接进入该房间；Boss 房不参与普通房间随机拓扑。

拓扑数据必须记录随机种子、房间坐标、门掩码、模板编号、清理状态和照明状态。

## 4. 模板数据

模板使用可读的数据文件保存，建议格式为 JSON 或 Python 数据类。每个模板至少包含以下字段：

```text
id
name
difficulty
tags
allowed_door_masks
player_spawn_cells
enemy_spawn_cells
switch_cells
solid_cells
pit_cells
crate_cells
decal_cells
```

门掩码使用 `N/E/S/W`。模板只在门掩码兼容时参与抽取。

## 5. 首批模板

| 编号 | 类型 | 结构 |
| --- | --- | --- |
| O01 | 开阔 | 四角少量柱子 |
| O02 | 开阔 | 两侧矮墙，中部净空 |
| O03 | 开阔 | 中央双掩体 |
| S01 | 对称 | 左右镜像柱阵 |
| S02 | 对称 | 上下镜像矮墙 |
| S03 | 对称 | 十字形中央区域 |
| C01 | 掩体 | 三段交错竖向矮墙 |
| C02 | 掩体 | 两条冲锋中断线 |
| D01 | 分割 | 中央横向隔断，双侧开口 |
| D02 | 分割 | 中央纵向隔断，上下开口 |
| P01 | 裂隙 | 两簇裂隙，中间保留桥道 |
| P02 | 裂隙 | 双侧裂隙和环形通路 |

模板可以左右镜像、上下镜像或旋转 180 度。变换后必须重新校验门、出生点和机关可达性。

模板的 `difficulty` 和 `tags` 必须参与选取：

- 第一关以难度 1 为主，可以少量使用难度 2。
- 第二关以难度 2 为主，可以使用难度 1 或 3。
- 第三关只使用难度 2 和 3。
- 相邻房间不得使用同一个模板编号。镜像和旋转不改变模板编号。
- `open` 不新增裂隙，只使用矮墙或矮墙加柱的组合。
- `cover` 只使用矮墙加双柱的掩体组合。
- `split` 只使用长矮墙加双柱的分割组合。
- `pit` 只使用两簇 2x2 小裂隙的组合。
- `heavy` 只使用长矮墙加双柱的冲锋中断组合。
- P02 同时带有 `pit` 和 `open`。它的主结构已经提供双侧裂隙，次级障碍按 `open` 规则放置，不继续叠加裂隙。

这些标签只限制次级障碍布局，不改变各关已经确定的敌人种类比例。

每个房间先放置模板定义的主结构，再加入受约束的次级障碍。次级障碍从短矮墙、单柱、双柱和小型裂隙等预设组合中抽取，不生成任意尺寸的随机矩形。

## 6. 空间规则

- 出生点周围 3x3 格绝对净空。
- 门内两格不得放置障碍、箱子、机关或敌人。
- 主要通路至少两格宽。
- 不可到达地块不得紧贴整个墙边形成封锁。
- 裂隙按 2 至 6 格簇状放置，必须保留绕行路线。
- 每个房间至少有一条连续绕行路线，玩家不应被迫停在死角射击。
- 重型僵尸房间至少有两个可中断冲锋的障碍。
- 快速僵尸房间保留不低于 55% 的开阔面积。
- 机关不得位于出生点直视线上，也不得位于唯一死角。
- 敌人出生时，两实体分离圆的边缘间距不得低于 8px。

硬障碍占用格包括主模板和次级障碍中的不可破坏墙、柱和裂隙，不包括外围墙、箱子、机关和非碰撞装饰。每关密度如下：

| 关卡 | 每房硬障碍占用格目标 | 次级障碍组数 |
| --- | ---: | ---: |
| 第一关 | 12 至 20 格 | 1 组 |
| 第二关 | 18 至 28 格 | 1 至 2 组 |
| 第三关 | 24 至 36 格 | 2 至 3 组 |

次级障碍不得只增加占用面积。每个房间至少保留一条长度不低于本房敌人最大感知距离的无遮挡直线冲锋路线。加入次级障碍后，第三关仍须能够按间距规则生成 13 只重型僵尸。

敌人和箱子按以下预算放置：

| 关卡 | 每房敌人数 | 整关敌人总数范围 | 箱子总数 |
| --- | ---: | ---: | ---: |
| 第一关 | 6 至 8 | 12 至 16 | 房间数 + 0 至 1 |
| 第二关 | 8 至 10 | 16 至 30 | 房间数 + 1 至 2 |
| 第三关 | 11 至 13 | 22 至 39 | 房间数 + 2 至 3 |

每个普通房间独立在对应范围内随机敌人数。整关总数由各房结果相加，不再平均分配预先抽取的总数。每个普通房间先放置一个箱子，再把额外箱子随机分配到普通房间。单房最多 13 个敌人，生成阶段仍须满足出生距离和实体间距检查。

## 7. 房间验证

生成阶段依次执行：

1. 按关卡难度和标签选择主模板，并排除相邻房间已经使用的模板编号。
2. 检查门掩码是否兼容。
3. 放置主模板障碍，并使用 BFS 检查出生点到所有门和机关的连通性。
4. 按本关数量范围逐组加入次级障碍。每加入一组后重新检查连通性、门内净空、出生安全区和两格主通路。
5. 检查硬障碍占用格、可行走面积和无遮挡直线冲锋路线。
6. 从候选点中抽取敌人和箱子位置。
7. 检查敌人出生点之间的间距，禁止碰撞圆重叠，并按本关上限执行最密集生成校验。
8. 再次检查玩家至少有一条逃离敌人包围的通路。

失败时更换模板，不在运行时修补结构性障碍。

## 8. 房间状态

- 玩家首次进入未清理战斗房时关闭相邻房门。
- 当前房间敌人全部死亡后开门，并永久记录该房间的清理状态。
- 已清理房间不再生成敌人。
- 箱子、金币和机关状态在当前关卡内保留。
- 玩家死亡后重新生成整个关卡，永久强化保留。
- 只有本关全部普通房间均被清理后才进入商店。

## 9. 第三关 Boss 房与结束流程

- 进入顺序固定为：第三关普通房间全部清理 -> 商店 -> Boss 房。
- Boss 房使用独立固定模板 `B01`，房内放置四个固定柱作为冲锋掩体，不生成普通敌人、箱子、照明机关或出口机关。模板在 `boss_spawn` 位置生成 Boss 实体。
- Boss 房进入时完全点亮，玩家可以正常移动，暂停菜单继续保留返回标题功能。
- `boss_spawn` 不得覆盖玩家出生安全区、墙体或固定障碍，Boss 初始位置必须能到达房间的主要冲锋路线。
- 房内固定障碍必须能够中断 Boss 冲锋，同时保留玩家绕行路线。第二阶段连续两次冲锋都要重新执行障碍碰撞与路线边界检查。
- Boss 碰撞框为 56x56px，实体分离半径为 28px。第一阶段为 100 点生命、1.0 px/帧基础速度、0.80 秒预警、6.0 px/帧冲锋速度、640px 最大冲锋距离、1 次冲锋、1.10 秒硬直、1.00 秒恢复和 2 点伤害。
- 第二阶段为 50 点生命、1.4 px/帧基础速度、0.40 秒预警、7.5 px/帧冲锋速度、每次 480px 最大冲锋距离、连续 2 次冲锋、0.60 秒硬直、0.50 秒恢复和 3 点伤害。第一冲正常结束后重新预警并锁定方向；任意一次冲锋撞到障碍都会取消本轮剩余冲锋。
- Boss 始终知道玩家位置，恢复期间接近玩家，预警结束时锁定方向，冲锋途中不转向。冲锋按不超过 8px 的分段检查移动轨迹，单次冲锋最多造成一次玩家接触伤害。
- Boss 所有战斗状态都可受伤。第一阶段溢出伤害不带入第二阶段，Boss 不显示生命条，也不掉落金币。
- Boss 第二阶段生命归零后停止 Boss 房更新，播放约 1 秒死亡效果，再进入开发中提示界面。界面显示“后续内容正在开发”和“按任意键返回标题画面”。
- 开发中提示界面接收任意键后返回标题画面，不进入商店，也不直接从 Boss 房跳回标题。

## 10. 实体碰撞

- 玩家、普通僵尸、快速僵尸和重型僵尸的实体分离半径分别为 12px、12px、9px 和 17px。
- 敌人移动完成后进行两两软分离。双方各承担一半修正距离，修正后不得进入墙体、障碍或不可到达地块。
- 玩家与僵尸发生接触伤害后也要分离，避免多个敌人与玩家共享同一位置。
- 冲锋僵尸可以推开其他僵尸，不造成友军伤害，也不因同类碰撞而眩晕。
- 子弹命中使用独立矩形受击框，尺寸分别为普通 28x28、快速 20x20、重型 38x38。

## 11. 照明

未激活机关时，视野半径为 224px。光斑外完全黑暗，外围墙轮廓仍然可见。机关激活后，当前房间永久恢复正常亮度。

视野遮罩只影响显示，不限制敌人感知。普通、快速和重型僵尸的感知距离分别为 288px、256px 和 320px，均大于 224px 视野半径。僵尸只有在玩家位于感知距离内且二者之间存在无遮挡直线冲锋路线时才进入预警。

视野外预警不显示声音、方向箭头、边缘红光或穿透黑暗的标记。僵尸进入视野后，仍显示自身的准备动作和红色预警圈。预警结束后锁定方向，冲锋期间不转向。普通、快速和重型僵尸的最大冲锋距离分别为 384px、320px 和 448px。

僵尸平时每隔 1.2 至 2.5 秒选择一个可达目标点随机游荡。撞到障碍时立即更换目标。冲锋结束并完成硬直后，先恢复游荡 0.4 至 0.8 秒，再允许下一次感知和冲锋。

## 12. 不采用的方案

- 不使用 WFC 生成战斗房。WFC 难以保证冲锋路线和遭遇节奏，制作邻接规则的成本也高于本项目需要。
- 不使用 BSP 切分单个房间。固定单屏房不需要递归分区。
- 不在运行时随机拉伸障碍贴图。
- 不让程序生成任意尺寸和位置的结构性墙体。运行时只能加入本规范定义的次级障碍组合，并在每次加入后重新验证房间。

后续如果模板池超过 40 个，可以增加编辑器或模板预览工具，但运行时仍从已验证模板中抽取。
