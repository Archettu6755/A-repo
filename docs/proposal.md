# 需求文档 —— 像素风肉鸽射击游戏（Demo）

## 1. 项目概述

### 1.1 项目目标

使用 **Python + Pygame** 开发一款可本地运行的像素风"肉鸽（Roguelike）"射击游戏，玩法参考《以撒的结合》的核心循环：**击杀敌人 → 收集金币 → 进入商店强化 → 进入下一关 → 难度提升**。

### 1.2 初版范围

本次为 **Demo 版本**，制作 **两关**，用于测试核心玩法效果与 **关卡刷新功能**（通关进入下一关、房间重置、难度递进）。后续版本再扩展为更多关卡。

## 2. 游戏背景与主题

- **主题风格**：像素风。
- **我方角色**：士兵。
- **敌方角色**：僵尸。

## 3. 核心玩法

### 3.1 操作方式

| 按键 | 功能 |
| ---- | ---- |
| W / A / S / D | 控制士兵上下左右移动 |
| F | 攻击（向当前朝向射击） |
| E | 打开/关闭属性面板（暂停并弹出） |
| ESC | 暂停 / 恢复 |
| 任意键 | 标题界面开始游戏 |
| 关闭窗口 | 退出游戏 |

- 斜向移动（如 W + D 同时按）**不做速度归一化**，斜向速度约为直向的 1.41 倍。

### 3.2 游戏循环

1. 关卡开始，房间内随机生成一批僵尸。
2. 玩家击败 **全部僵尸** 后通过本关。
3. 通关后进入 **商店界面**。
4. 购买完成后进入下一关（Demo 版共 **两关**，第二关通关后完成游戏）。
5. 生命值归零 → 游戏失败，**重新开始本关**。

### 3.3 胜利与失败条件

- **胜利**：击败全部关卡的敌人（Demo 版为通关第二关）。
- **失败**：生命值归零。失败后重新开始当前关卡（永久强化保留，见第 6 节）。

## 4. 主要对象

### 4.1 士兵（玩家）

- 初始生命值、攻击力、射速、移速由文档默认值设定（详见第 7 节），可通过商店永久提升。
- 死亡后在本关起点重生，属性强化保留。

### 4.2 僵尸（敌人）

**冲锋型** 行为模式：

- 平时缓慢接近玩家。
- 发现玩家（**距离 200 像素内**）后进入 **冲锋状态**：速度提升至 **2.5 倍** 冲向玩家当前位置。
- 冲锋结束后（撞到玩家 / 撞到墙 / 冲锋距离耗尽）进入 **硬直（眩晕）0.5 秒**，短暂停顿后恢复正常游荡。
- 僵尸按类型区分，**不同类型的僵尸基础血量与碰撞伤害不同**：

| 类型 | 血量 | 碰撞伤害 | 速度 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 普通僵尸 | 2 | 1 | 慢 | 基础型，最常见 |
| 快速僵尸 | 1 | 1 | 快 | 血少但机动性强 |
| 重型僵尸 | 3 | 2 | 慢 | 血厚、伤害高 |

- 三种类型随机生成。

### 4.3 攻击方式（射击）

- 按 F 向玩家当前朝向发射一颗子弹。
- 子弹有 **短暂冷却时间**，不可无限制连发。
- **子弹速度 6 像素/帧，射程 300 像素**，飞出射程后消失。
- 子弹击中僵尸后造成伤害并消失；**不能穿墙**，击中墙壁后消失。
- 僵尸死亡时有一定概率掉落金币。

### 4.4 受伤判定

- 玩家被僵尸碰撞/冲撞后扣除对应血量，并获得 **0.5 秒无敌帧**（期间闪烁提示，不受伤害）。

## 5. 地图与关卡

### 5.1 房间生成

- 游戏窗口尺寸 **1280x720**。
- 每关为一个矩形房间，**位置固定居中**，**尺寸随机**（宽 **768~1024** 像素，高 **432~576** 像素，均占窗口 60%~80%）。
- 房间四边有墙壁（厚 **28 像素**），玩家与子弹不可穿过。
- 僵尸在房间内随机位置生成。
- **关卡刷新**：通关商店后进入下一关，房间尺寸重新随机、僵尸重新生成、金币等本关临时状态重置（永久强化保留）。
- **难度递进**：每进入下一关，僵尸数量提升、重型僵尸出现概率增加（具体见第 7 节）。
- Demo 版本共两关，随机房间尺寸与难度递进逻辑与多关版本一致，便于后续扩展。

### 5.2 商店

- 玩家击败全部僵尸后进入 **商店界面**。
- 商店使用 **金币** 购买强化。
- 操作方式：**键盘上下方向键选择商品，回车键购买**。
- 金币不足时：**按钮置灰 + 显示红色提示文字**，不扣除金币。

### 5.3 货币：金币

- 僵尸被击杀时掉落金币。
- 玩家走到金币上自动拾取。
- 金币 **20 秒后消失**（未拾取则流失）。
- 金币用于商店消费。

## 6. 数值与成长体系

### 6.1 商店可购项目（多属性、可重复购买）

| 商品 | 效果 | 说明 |
| ---- | ---- | ---- |
| 攻击力 +1 | 永久提升子弹伤害 | 可重复购买 |
| 生命上限 +1 | 永久提升最大生命值 | 可重复购买 |
| 射速提升 | 永久缩短子弹冷却时间 | 可重复购买 |
| 移速提升 | 永久提升移动速度 | 可重复购买 |
| 回血 | 恢复一定量生命值 | 可重复购买 |

各商品价格由配置文件设定，随购买次数可逐次涨价（待定，默认不涨价）。

### 6.2 永久与临时属性

- **永久强化**：商店购买的属性提升（攻击力、生命上限、射速、移速），在死亡重开本关后 **保留**。
- **临时状态**：本关内金币、当前生命值、僵尸位置等，死亡后 **重置**（金币清零，僵尸重生）。

### 6.3 死亡惩罚

死亡后：

- 永久强化保留。
- 当前关卡金币清零。
- 僵尸重新生成，本关重新挑战。

## 8. 画面表现（Demo 阶段）

- 玩家、僵尸、子弹、墙壁、金币均使用 **纯色方块/矩形占位**，颜色区分：
  - 士兵：蓝色方块
  - 僵尸：绿色方块（不同类型深浅/大小区分）
  - 子弹：黄色小方块
  - 墙壁：灰色边框/深色矩形
  - 金币：金色小方块
  - 背景：深色
- 画面上方 HUD **左上角显示生命值血条**；其余属性（攻击力、射速、移速）与金币不在 HUD 常驻显示。
- **鼠标光标隐藏**，全程不使用鼠标操作。
- 按 **E 键打开属性面板**（游戏暂停，半透明弹窗），展示：生命值、攻击力、射速、移速、金币数量；再按 E 或 ESC 关闭并恢复游戏。
- HUD 及界面文字使用 **系统中文字体**（如文泉驿/Noto 等），保证汉字正常显示。
- 商店界面为独立界面，列出商品、价格与购买按钮。

## 9. 界面与流程

```
启动游戏 → 标题界面（按任意键开始）
    → 第一关（移动/射击/拾取金币，ESC 暂停）
    → 击败全部敌人 → 商店界面（↑↓ 选择，回车购买）
    → 第二关（房间重置、难度提升）
    → 击败全部敌人 → 商店界面
    → 购买完成后 → 返回标题界面
    → 死亡 → 失败提示 → 重开本关（强化保留）
```

## 10. 技术选型

- 语言：Python 3
- 游戏库：Pygame
- 运行方式：本地运行 `python main.py`（或项目约定的启动命令）
- 数值配置集中存放，便于调优

## 11. 非目标（本版本不做）

- 不做超过两关的多关卡流程（Demo 版两关，用于测试关卡刷新）。
- 不做动画、音效、特效（后期可加）。
- 不做存档系统。
- 不做 Boss、道具掉落、随机道具等进阶肉鸽要素（后期可加）。

## 12. 验收标准（Demo）

1. 游戏可在本地启动并流畅运行（稳定 60 FPS）。
2. WSAD 移动、F 射击正常工作，射击有冷却；斜向移动不归一化。
3. 标题界面按任意键开始；游戏中 ESC 可暂停/恢复。
4. 僵尸按"冲锋型"行为移动（200 像素触发、2.5 倍速、0.5 秒硬直），分普通/快速/重型三种，数值符合第 7 节。
5. 击杀僵尸掉落金币（50% 概率），金币 20 秒后消失，可拾取计数。
6. 击败全部僵尸后进入商店界面，↑↓ 选择、回车购买；金币不足时按钮置灰并显示红字提示。
7. 强化在死亡重开后保留；本关敌人重置；金币清零。
8. 生命归零后正确显示失败并重开本关。
9. HUD 左上角血条正常显示；按 E 弹出属性面板（生命/攻击/射速/移速/金币），再次按 E 或 ESC 关闭并恢复游戏；中文显示正常。
10. **关卡刷新**：第一关通关商店后正确进入第二关，房间重置、僵尸重新生成、难度提升（数量 8~15、重型僵尸概率 35%）。
11. 第二关通关（购买完成后）正确返回标题界面。
