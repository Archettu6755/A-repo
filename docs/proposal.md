# 需求文档 —— 像素风肉鸽射击游戏（Demo）

## 1. 项目概述

### 1.1 项目目标

使用 **Python + Pygame** 开发一款可本地运行的像素风"肉鸽（Roguelike）"射击游戏，玩法参考《以撒的结合》的核心循环：**击杀敌人 → 收集金币 → 进入商店强化 → 进入下一关 → 难度提升**。

### 1.2 初版范围

本次为 **Demo 版本**，制作 **两关**，用于测试核心玩法效果与 **关卡刷新功能**（通关进入下一关、房间重置、难度递进）。后续版本再扩展为更多关卡。

## 2. 游戏背景与主题

- **主题风格**：像素风。
- **我方角色**：士兵。
- **敌方角色**：僵尸。

## 3. 核心玩法

### 3.1 操作方式

| 按键 | 功能 |
| ---- | ---- |
| ↑ / ↓ / ← / → | 控制士兵上下左右移动 |
| F | 攻击（向当前朝向射击） |
| E | 打开/关闭属性面板（暂停并弹出） |
| ESC | 暂停 / 恢复 |
| 任意键 | 标题界面开始游戏 |
| 关闭窗口 | 退出游戏 |

- 斜向移动（如 → + ↓ 同时按）**不做速度归一化**，斜向速度约为直向的 1.41 倍。

### 3.2 游戏循环

1. 关卡开始，房间内随机生成一批僵尸。
2. 玩家击败 **全部僵尸** 后通过本关。
3. 通关后进入 **商店界面**。
4. 购买完成后进入下一关（Demo 版共 **两关**，第二关通关后完成游戏）。
5. 生命值归零 → 游戏失败，**重新开始本关**。

### 3.3 胜利与失败条件

- **胜利**：击败全部关卡的敌人（Demo 版为通关第二关）。
- **失败**：生命值归零。失败后重新开始当前关卡（永久强化保留，见第 6 节）。

## 4. 主要对象

### 4.1 士兵（玩家）

- 初始生命值、攻击力、射速、移速由文档默认值设定（详见第 7 节），可通过商店永久提升。
- 死亡后在本关起点重生，属性强化保留。

### 4.2 僵尸（敌人）

**冲锋型** 行为模式：

- 平时缓慢接近玩家。
- 发现玩家（**距离 160 像素内**）后进入 **冲锋状态**：速度提升至 **3 倍** 冲向玩家当前位置。
- 冲锋结束后（撞到玩家 / 撞到墙 / 撞到障碍物 / 冲锋距离耗尽）进入 **硬直（眩晕）0.6 秒**，短暂停顿后恢复正常游荡。
- 僵尸按类型区分，**不同类型的僵尸基础血量与碰撞伤害不同**：

| 类型 | 血量 | 碰撞伤害 | 速度 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 普通僵尸 | 3 | 1 | 慢 | 基础型，最常见 |
| 快速僵尸 | 2 | 1 | 快 | 血少但机动性强 |
| 重型僵尸 | 4 | 2 | 慢 | 血厚、伤害高 |

- 三种类型随机生成。

### 4.3 攻击方式（射击）

- 按 F 向玩家当前朝向发射一颗子弹。
- 子弹有 **短暂冷却时间**，不可无限制连发。
- **子弹速度 6 像素/帧，射程 300 像素**，飞出射程后消失。
- 子弹击中僵尸后造成伤害并消失；**不能穿墙**，击中墙壁后消失。
- 僵尸死亡时有一定概率掉落金币。

### 4.4 受伤判定

- 玩家被僵尸碰撞/冲撞后扣除对应血量，并获得 **0.5 秒无敌帧**（期间闪烁提示，不受伤害）。

## 5. 地图与关卡

### 5.1 房间生成

- 游戏窗口尺寸 **1280x720**。
- 每关由 **1~3 个房间**组成，**位置固定居中**（垂直方向下移 48 像素，避免与顶部 HUD 重叠），**尺寸固定为窗口 80%（1024x576 像素）**，不再随机。
- 房间四边有墙壁（厚 **20 像素**），玩家与子弹不可穿过。
- 僵尸在房间内随机位置生成。
- **多房间与开门机制**：房间间用门连接；**门始终可通行**，玩家可直接穿过门进入下一房间（不要求先清空当前房间）；**全部房间的僵尸清空**后本关通过进入商店。
- **单房切换显示（当前实现）**：每次**只显示当前房间**，进入下一个房间时画面**瞬间切换**到新房间（简单过渡，先做 demo）。
- **镜头滚动过渡（后续目标，本轮不做）**：后续将画面过渡升级为**镜头滚动**——画面随玩家移动平滑平移滚动到下一房间，本版本暂不实现。
- **地图生成算法优化（后续目标，本轮不做）**：障碍物、不可到达地块、墙壁的布局与数量将交由更复杂的地图生成算法（如 BSP 分割、Wave Function Collapse 等程序化生成方案）实现，具体算法将参考开源项目调研后确定，以实现更强的空间限制与多样性。

### 5.2 室内障碍物

房间内除四边墙壁外，还会生成**地形障碍**：

| 障碍物 | 说明 |
| ---- | ---- |
| 柱子 | 小面积方块，随机分布在房间内 |
| 平面墙 | 较大面积的矩形墙体，成块分布 |
| 不可到达地块 | 遮挡区域（如水池/裂隙），玩家与僵尸不可通过 |

- 玩家、子弹、僵尸均**不可穿过**障碍物。
- 僵尸冲锋撞上障碍物后**眩晕 0.6 秒**（同撞墙）。
- 障碍物数量随关卡递进（见 5.4）。
- 障碍物生成时保证不与玩家出生点、房间门冲突。
- **视觉表现**：障碍物统一使用**冷色调（灰蓝色系）**并带深色描边边框，与暖色的可破坏物形成冷暖对比，区分"不可破坏"与"可破坏"。

### 5.3 可破坏物（箱子）

- 房间内随机生成 **2~5 个箱子**。
- 子弹命中可破坏（需命中多次，血量高于普通僵尸），打碎后 **50% 概率掉落金币**。
- 箱子用于遮挡与战术利用，后续版本可扩展掉落道具等内容（设计上预留拓展空间）。
- **视觉表现**：箱子使用**暖色调（橙棕色系）**、无边框，与冷色调障碍物明显区分。

### 5.4 关卡地形差异

- 地形障碍与箱子数量**随关卡递进**：第一关以空旷为主（障碍少），第二关障碍、箱子明显增多，配合更多僵尸提升难度。
- **尺寸多样化**：障碍物与箱子的尺寸在基础值 ±20% 范围内随机，避免千篇一律的正方形。

### 5.5 视野与机关

- **视野范围**：以玩家为圆心的**圆形视野**，半径 **220 像素**。
- **光斑表现（重点）**：**玩家周围必须始终显示可见光斑**——即以玩家为中心的圆形亮区，光斑内正常显示（角色、敌人、地形均可见），光斑外为全黑。光斑是玩家的主要可视区域，随玩家移动。
- **视野外区域**：光斑之外**完全黑幕**，不可见（敌人、障碍、金币、机关均不可见）。
- **地图边缘显示（重点）**：**房间墙壁（地图边缘）始终可见，不被黑幕遮挡**——无论房间是否点亮，玩家都能看到房间边界轮廓，用于判断地图范围。
- **机关（点亮装置，功能强调）**：每个房间 **1 个**，放置于房间内随机位置。**机关的唯一功能是：触发后照亮整个房间**——该房间内所有区域（光斑之外的部分）恢复可见，全房间永久点亮（本关内保持），此后该房间不再受视野限制。
- **触发方式**：玩家**走近碰撞**即自动触发，无需按键。
- **可见性**：机关在视野外**完全不可见**，玩家需通过探索发现；触发后机关变绿显示已激活。
- 视野机制为可选增强：触发机关是探索重点，未触发前房间暗区保持黑幕。

### 5.6 商店

- 玩家清空全部房间后进入 **商店界面**。
- 商店使用 **金币** 购买强化。
- 操作方式：**↑/↓ 选择商品，F 购买/确认**；ESC 退出商店（进入下一关时需选择底部确认项或按 ESC）。
- 金币不足时：**按钮置灰 + 显示红色提示文字**，不扣除金币。

### 5.7 货币：金币

- 僵尸被击杀时掉落金币（50% 概率）。
- 玩家走过金币自动拾取。
- 金币 **20 秒后消失**（未拾取则流失）。
- 金币用于商店消费。

## 6. 数值与成长体系

### 6.1 商店可购项目（多属性、可重复购买）

| 商品 | 初始价格 | 涨价规则 | 成长上限 | 效果 | 说明 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 攻击力 +1 | 2 金币 | 每次 +2 | 攻击力上限 5（初始 1，可购 4 次） | 永久提升子弹伤害 | 达到上限后不可再购 |
| 生命上限 +1 | 5 金币 | 每次 +3 | 生命上限 10（初始 5，可购 5 次） | 永久提升最大生命值 | 达到上限后不可再购 |
| 射速提升 | 6 金币 | 每次 +6 | 冷却最低 0.15 秒（初始 0.3，可购 3 次） | 永久缩短子弹冷却时间 | 达到上限后不可再购 |
| 移速提升 | 5 金币 | 每次 +5 | 移速上限 5（初始 3，可购 4 次） | 永久提升移动速度 | 达到上限后不可再购 |
| 回血 | 2 金币 | 每次 +1 | 不设上限 | 恢复一定量生命值 | 受金币自然限制 |

- **重复购买涨价**：同一商品每次购买后价格按上表规则上涨（例：攻击力 2→4→6→8…；回血 2→3→4→5…），永续上涨无上限。
- **成长上限**：攻击力、生命上限、射速、移速达到上限后，该商品**锁定不可购买**（卡片置灰）；回血无上限。
- 价格由配置文件集中管理，便于调优。

### 6.2 永久与临时属性

- **永久强化**：商店购买的属性提升（攻击力、生命上限、射速、移速），在死亡重开本关后 **保留**。
- **临时状态**：本关内金币、当前生命值、僵尸位置等，死亡后 **重置**（金币清零，僵尸重生）。

### 6.3 死亡惩罚

死亡后：

- 永久强化保留。
- 当前关卡金币清零。
- 僵尸重新生成，本关重新挑战。

## 8. 画面表现（Demo 阶段）

- 玩家、僵尸、子弹、墙壁、金币均使用 **纯色方块/矩形占位**，颜色区分：
  - 士兵：蓝色方块
  - 僵尸：绿色方块（不同类型深浅/大小区分）
  - 子弹：黄色小方块
  - 墙壁：灰色边框/深色矩形
  - 金币：金色小方块
  - 背景：深色
- 画面上方 HUD **左上角显示生命值血条**；其余属性（攻击力、射速、移速）与金币不在 HUD 常驻显示。
- **鼠标光标隐藏**，全程不使用鼠标操作。
- 按 **E 键打开属性面板**（游戏暂停，半透明弹窗），展示：生命值、攻击力、射速、移速、金币数量；再按 E 或 ESC 关闭并恢复游戏。
- HUD 及界面文字使用 **系统中文字体**（如文泉驿/Noto 等），保证汉字正常显示。
- 商店界面为独立界面，列出商品、价格与购买按钮。

## 9. 界面与流程

```
启动游戏 → 标题界面（按任意键开始）
    → 第一关（1~3 个房间：移动/射击/拾取金币，ESC 暂停）
    → 清空当前房间 → 开门进入下一房间
    → 清空全部房间 → 商店界面（↑/↓ 选择，F 购买）
    → 第二关（房间布局重置、障碍与僵尸增多）
    → 清空全部房间 → 商店界面
    → 购买完成后 → 返回标题界面
    → 死亡 → 失败提示 → 重开本关（强化保留）
```

## 10. 技术选型

## 12. 验收标准（Demo）

1. 游戏可在本地启动并流畅运行（稳定 60 FPS）。
2. 方向键移动、F 射击正常工作，射击有冷却；斜向移动不归一化。
3. 标题界面按任意键开始；游戏中 ESC 可暂停/恢复。
4. 僵尸按"冲锋型"行为移动（160 像素触发、3 倍速、0.6 秒硬直），分普通/快速/重型三种（血量 3/2/4），数值符合第 7 节。
5. 击杀僵尸掉落金币（50% 概率），金币 20 秒后消失，可拾取计数。
6. **多房间布局**：每关 1~3 个房间，清空当前房间僵尸后门开启，全部房间清空后进入商店。
7. **室内障碍物**：柱子/平面墙/不可到达地块正确生成，玩家、子弹、僵尸不可穿过，冲锋撞障碍物眩晕。
8. **可破坏物**：箱子可被子弹打碎（需多次命中），50% 概率掉金币。
9. **地形递进**：第二关障碍物与箱子数量多于第一关。
10. 击败全部僵尸后进入商店界面，↑/↓ 选择、F 购买；金币不足时按钮置灰并显示红字提示。
11. 强化在死亡重开后保留；本关敌人重置；金币清零。
12. 生命归零后正确显示失败并重开本关。
13. HUD 左上角血条正常显示；按 E 弹出属性面板（生命/攻击/射速/移速/金币），再次按 E 或 ESC 关闭并恢复游戏；中文显示正常。
14. **关卡刷新**：第一关通关商店后正确进入第二关，房间布局重置、僵尸重新生成、难度提升（数量 8~15、重型僵尸概率 35%、障碍增多）。
15. **视野与机关**：玩家周围始终显示圆形光斑（半径 220px），光斑外全黑；房间墙壁（地图边缘）始终可见不被遮挡；每房间 1 个机关，走近碰撞触发后该房间全部区域点亮（永久）。
16. **单房切换**：每关 1~3 个房间，每次只显示当前房间，穿门后画面切换（本轮为瞬间切换；镜头滚动列入后续目标）。
17. 第二关通关（购买完成后）正确返回标题界面。
