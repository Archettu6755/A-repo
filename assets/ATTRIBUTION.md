# 资源来源与许可证

## 原创资源

项目角色、僵尸、环境、物件、效果和 UI 由项目自行设计和绘制。AI 生成图作为制作母版，运行时 PNG 由 `tools/build_runtime_assets.py` 从母版切片和缩放，接入前按 `docs/art.md` 检查。

## 字体候选

- Ark Pixel Font，作者 TakWolf，SIL Open Font License 1.1。
- Fusion Pixel Font，作者 TakWolf，SIL Open Font License 1.1。

字体正式加入仓库时，需要同时保存字体文件、许可证副本、版本号和下载地址。
